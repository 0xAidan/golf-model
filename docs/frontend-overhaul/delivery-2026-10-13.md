# Frontend delivery measurement, 13 October 2026

The production build succeeds. The matchup desk loads the notification host only when a legacy tool is first opened, then retains it so notifications survive navigation. Error reporting is loaded only with a configured DSN and finishes initialization before React renders. Its existing scrubbing and route recovery IDs are unchanged. The legacy laboratory and prediction workspaces use the existing retry and route error boundaries, loading their charts only on demand. Theme behavior is unchanged.

The main entry is 13.7% smaller. The HTML preload total is **not** the complete route download: it excludes chunks loaded at runtime, including the matchup desk. These figures measure build artifacts, not live network performance or server latency.

Both sources were built using the same installed dependencies, including Vite 8.0.3. The old source was exported with `git archive HEAD frontend` into a temporary directory, linked to the current `node_modules`, and built there with Vite. It did not replace the current preview build. Each JavaScript file was measured with Node's `gzipSync` using default compression.

The previous budget script ended its pipeline at the gzip transform. It could resolve before the readable output was fully counted, producing inconsistent undercounts. The script now drains output into a counting writable stream; its result matches `gzipSync`. The historical June baseline remains recorded. The remeasured old source and current source are added separately, and future builds use the current measured entry as the baseline with the existing 5% allowance.

Validation includes an integration test proving the notification host is absent on first desk load, appears for legacy tools, and remains mounted after navigation back. Error reporting tests cover missing configuration, successful initialization before startup continues, and safe continuation after reporting failure. Legacy route tests pre-transform their module graph before route assertions; lazy activation is tested independently, and assertion timeouts are unchanged.
